Evasion What it costs the launderer Rules Shipped Model alone

The rule layer is brittle. An informed launderer takes it from 139 cases to 14, a 90% collapse, using nothing more exotic than smaller payments and longer gaps.

The model is the robust half. It degrades to 44 rather than collapsing, and catches more than the rules in the five scenarios that actually degrade the rule layer. Where the rules hold, they stay ahead. The model keys on behaviour, meaning amount shape, velocity and counterparty spread, so evading it costs the launderer something real. That inverts the result above: on clean data the rules detect and the model filters noise, but under adaptation the roles swap.

The architecture is the weak link, not the model. Under full evasion the shipped system catches 39 where the model alone at the same alert budget catches 44, because the design gates the model behind rule corroboration. Right against noise, wrong against an adversary: the tiering should be a dial, not a fixture.

The queue

What an analyst opens on Monday. Every row carries the reason it surfaced; expand one to see the evidence the rule actually matched. References are anonymised: the source file prefixed its planted rows, so publishing the raw IDs would give the answer away.

Method. Four rules (structuring, rapid fund movement, high-risk jurisdiction, round amounts) run first. Targeted typologies escalate on their own; broad screens escalate only when an Isolation Forest also places the transaction in the top 1% of the book on amount shape, timing, velocity and counterparty spread. The model never sees jurisdiction, so the two layers fail independently.

Honest limits. The 98.6% figure is largely the story of one badly-calibrated jurisdiction screen; a bank with better-tuned rules would see less. “All 139 cases” means all known cases: the true false-negative rate is unknowable here, as it is in production.
